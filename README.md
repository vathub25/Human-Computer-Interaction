# Human-Computer-Interaction
University projects from the Human-Computer Interaction (MMI) course, focusing on UI/UX design, interactive prototyping, usability, and web accessibility.

## About

These projects were completed as part of my Media and Communication Informatics studies at Reutlingen University.

Throughout the course, I worked on different topics, including:

- User Interface (UI) and User Experience (UX) design
- Human-computer interaction principles
- Interactive prototyping
- Usability and user-centered design
- Web accessibility and inclusive design
- Responsive web design
- Visual design and interface development

## Projects

### Project 01 – Car Infotainment UI (Team of 4)

Design and documentation of a car infotainment user interface, focusing on usability, visual structure, and intuitive interaction.

### Project 02 – mkiVerse Memory Game (Individual Project)

Development of an interactive memory game prototype, exploring user interaction, interface design, and playful learning experiences.

### Project 03 – Accessible Travel Blog (Individual Project)

Development of a travel website using HTML and CSS, focusing on accessible web design, user-friendly navigation, and visual presentation.
